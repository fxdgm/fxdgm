## Installation

As a numerical solver, mainly FEniCSx was used and installed via conda.

```
conda create -n fenicsx-env
conda activate fenicsx-env
conda install -c conda-forge fenics-dolfinx=0.8.0 mpich=4.2.2 pyvista=0.44.1 matplotlib=3.8.4 numpy=2.0.1 scipy=1.14.0
```
